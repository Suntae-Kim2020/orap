## 2. 기술분야

본 발명은 연구성과 분석 시스템에 관한 것으로, 더욱 상세하게는 복수의 계량서지학적(Bibliometric) 지표를 계층적 가중치 구조로 결합하여 연구자의 종합 연구력을 정량화하고, 학문분야별 연구전략을 자동 분류하여 제시하는 컴퓨터 구현 시스템 및 방법에 관한 것이다.

**기술분류:**
- 주분류: 정보통신 > 소프트웨어 > 기업/공공 솔루션 SW (IC05)
- 부분류: 데이터 분석/처리 시스템, 연구정보관리시스템(CRIS)

---

## 3. 배경기술 및 종래기술의 문제점

### 3.1 배경기술

대학 및 연구기관에서는 연구자의 연구 역량을 평가하고, 전략적 연구 방향을 수립하기 위해 다양한 계량서지 지표를 활용하고 있다. 대표적인 지표로는 FWCI(Field-Weighted Citation Impact), h-index, 논문 수, 피인용 횟수, Top 저널 게재율 등이 있다.

현재 이러한 지표를 제공하는 상용 시스템으로는 Elsevier社의 SciVal, Clarivate社의 InCites, Digital Science社의 Dimensions 등이 있다.

### 3.2 종래기술의 문제점

| 문제점 | 상세 내용 |
|--------|----------|
| **지표의 개별적 제공** | 기존 시스템은 FWCI, h-index, 논문수 등 각 지표를 개별적으로 나열하여 제공할 뿐, 이를 종합한 단일 점수를 제공하지 않아 연구자 간 비교가 어려움 |
| **인용 분석의 한계** | 실제 인용수와 분야별 기대 인용수 간의 갭(Gap)을 분석하여 지원이 필요한 연구자를 식별하는 기능이 부재함 |
| **전략 분류의 수동성** | 학문분야별 연구 현황 데이터는 제공하나, 전략적 의사결정을 위한 자동 분류 체계가 없어 사용자가 직접 해석해야 함 |
| **점수 산정의 불투명성** | 지표 산출 과정이 블랙박스로 제공되어 사용자가 결과의 근거를 검증하기 어려움 |
| **높은 비용** | 상용 시스템의 라이선스 비용이 고가여서 중소규모 기관의 활용이 제한됨 |

## 4. 발명의 목적

### 4.1 기술적 과제

본 발명은 상기한 종래기술의 문제점을 해결하기 위한 것으로, 다음의 기술적 과제를 해결하고자 한다.

1. 복수의 계량서지 지표를 **계층적 가중치 구조**로 통합하여 **단일 종합점수**를 산출하는 연구자 평가 방법 제공
2. **인용갭(Citation Gap)** 분석을 통해 연구지원 우선대상을 자동 식별하는 방법 제공
3. 학문분야를 **품질(FWCI)과 규모(논문수)** 기준으로 **4분면 매트릭스**에 자동 분류하는 연구전략 도출 방법 제공
4. 점수 산정 근거를 **논문 단위 드릴다운(Drilldown)**으로 투명하게 검증할 수 있는 시스템 제공

### 4.2 발명의 효과

- 연구자 간 객관적 비교를 위한 표준화된 종합점수 제공
- 연구지원 자원의 효율적 배분을 위한 의사결정 지원
- 기관의 연구 포트폴리오 전략 수립 지원
- 평가 결과의 투명성 및 신뢰성 확보

### 5.2 핵심 기술 구성요소

#### 5.2.1 연구자 종합점수 산정 방법 (제1발명)

본 발명의 핵심인 연구자 종합점수는 **핵심지표(80점)**와 **보조지표(10점)**의 계층적 구조로 산출된다.

**[점수 산출 체계]**

| 구분 | 지표 | 배점 | 산정 기준 |
|------|------|:----:|----------|
| **핵심지표** | FWCI | 35점 | ≥10: 35점, ≥8: 30점, ≥6: 25점, ≥4: 20점, ≥2: 15점, <2: 10점 |
| | Top 10% 피인용 논문 | 20점 | ≥3편: 20점, ≥1편: 15점, 0편: 10점 |
| | 상위저널 비율 | 15점 | ≥10%: 15점, <10%: 5점 |
| | 국제협력 FWCI | 10점 | ≥2.0: 10점, ≥1.5: 7점, ≥1.0: 4점, <1.0: 1점 |
| **보조지표** | SDG 관련 연구 | 3점 | 유: 3점, 무: 0점 |
| | Open Access | 2점 | 유: 2점, 무: 0점 |
| | Topic Prominence | 5점 | 평균 ≥90%: 5점, <90%: 0점 |
| **합계** | | **90점** | |

**[알고리즘 수식]**

```
총점 = 핵심지표_소계 + 보조지표_소계

핵심지표_소계 = f(FWCI) + f(Top10%) + f(상위저널) + f(국제협력)
보조지표_소계 = f(SDG) + f(OA) + f(TopicProm)

단, f(x)는 각 지표별 구간 매핑 함수
```

**[특징적 구성]**
- FWCI는 **평균값(mean)** 또는 **중앙값(median)** 중 사용자가 선택 가능
- 각 점수 항목별 기여 논문을 **드릴다운**으로 조회하여 투명성 확보

#### 5.2.2 인용갭 기반 연구지원 대상자 식별 방법 (제2발명)

**[인용갭 정의]**

```
인용갭(Citation Gap) = 실제인용수(Σ citations) - 기대인용수(Σ field_citation_average)
```

- **기대인용수**: 각 논문이 속한 학문분야의 평균 인용수 합계
- **실제인용수**: 해당 연구자의 논문이 실제로 받은 인용수 합계

**[지원대상 식별 조건]**

| 조건 | 임계값 | 의미 |
|------|:------:|------|
| 인용갭 | < 0 | 분야 평균 대비 인용 부족 |
| 상위저널 게재비율 | ≥ 30% | 연구 품질은 우수 |
| 논문 수 | ≥ 10편 | 충분한 연구 활동 |

**[작용 효과]**
- 인용갭이 음수이면서 상위저널 게재율이 높은 연구자 = "품질은 좋으나 인용이 부족한 연구자"
- 이들에게 홍보, 네트워킹, 학술활동 지원 등 맞춤형 지원 전략 제안

#### 5.2.3 학문분야별 연구전략 자동분류 방법 (제3발명)

**[4분면 매트릭스 분류]**

```
                    품질(FWCI)
                 낮음         높음
           ┌──────────┬──────────┐
     높음  │ 규모 우위 │ 핵심 강점 │
 규모      │  (info)  │ (success)│
(논문수)   ├──────────┼──────────┤
     낮음  │ 육성 필요 │ 성장 분야 │
           │ (warning)│ (primary)│
           └──────────┴──────────┘
```

**[분류 기준]**

| 전략 등급 | 분류 조건 | 전략적 의미 |
|----------|----------|------------|
| **핵심 강점** | FWCI ≥ 1.5 AND 국제협력비율 ≥ 40% | 집중 투자 및 유지 |
| **성장 분야** | FWCI ≥ 1.0 | 품질 우수, 규모 확대 필요 |
| **규모 우위** | 논문 수 ≥ 50편 | 규모는 크나 질적 개선 필요 |
| **육성 필요** | 상기 조건 미충족 | 선택과 집중 또는 구조조정 |

**[추가 분석 지표]**
- Top 저널 게재비율
- Top 10% 피인용 비율
- SDG 관련 연구 비율
- 산학협력 비율
- 특허인용 비율

## 8. 청구범위 (안)

### [독립항 1] 연구자 종합점수 산정 방법

연구자의 연구성과를 평가하는 컴퓨터 구현 방법에 있어서,
(a) 연구자의 논문 데이터로부터 필드가중인용지수(FWCI)를 추출하는 단계;
(b) 상기 FWCI를 기설정된 구간별 점수표에 매핑하여 FWCI 점수를 산출하는 단계;
(c) 상기 연구자의 Top 10% 피인용 논문 수를 기준으로 피인용 점수를 산출하는 단계;
(d) 상기 연구자의 논문 중 상위저널 게재 비율을 산출하여 저널품질 점수를 산출하는 단계;
(e) 상기 연구자의 국제협력 논문의 평균 FWCI를 산출하여 국제협력 점수를 산출하는 단계;
(f) 상기 (b)~(e) 단계의 점수를 합산하여 핵심지표 점수를 산출하는 단계;
(g) SDG 관련 연구, 오픈액세스, Topic Prominence를 포함하는 보조지표 점수를 산출하는 단계;
(h) 상기 핵심지표 점수와 보조지표 점수를 합산하여 연구자 종합점수를 산출하는 단계;
를 포함하는 것을 특징으로 하는 연구자 종합평가 방법.

### [종속항 2]
제1항에 있어서, 상기 FWCI는 개별 논문 FWCI의 중앙값(median) 또는 평균값(mean) 중 사용자 선택에 따라 적용되는 것을 특징으로 하는 방법.

### [종속항 3]
제1항에 있어서, 상기 방법은 각 점수 항목별로 기여한 개별 논문 목록을 드릴다운(drilldown) 방식으로 제공하여 점수 산정의 근거를 투명하게 검증할 수 있도록 하는 단계를 더 포함하는 것을 특징으로 하는 방법.

### [독립항 4] 인용갭 기반 연구지원 대상자 식별 방법

연구지원 대상자를 식별하는 컴퓨터 구현 방법에 있어서,
(a) 연구자의 각 논문에 대해 해당 분야의 평균 인용수(Field Citation Average)를 조회하는 단계;
(b) 상기 분야별 평균 인용수의 합계를 산출하여 기대인용수를 산정하는 단계;
(c) 상기 연구자의 논문들이 실제로 받은 인용수 합계를 산출하여 실제인용수를 산정하는 단계;
(d) 상기 실제인용수에서 상기 기대인용수를 감산하여 인용갭을 산출하는 단계;
(e) 상기 인용갭이 음수인 연구자 중 상위저널 게재비율이 기설정된 임계값 이상인 연구자를 연구지원 우선대상으로 분류하는 단계;
를 포함하는 것을 특징으로 하는 연구지원 대상자 식별 방법.

### [독립항 5] 학문분야별 연구전략 자동분류 시스템

기관의 학문분야별 연구전략을 도출하는 컴퓨터 구현 방법에 있어서,
(a) 논문 데이터베이스로부터 ASJC 분야 코드를 추출하는 단계;
(b) 각 분야별로 논문 수, 평균 FWCI, 국제협력 비율을 집계하는 단계;
(c) 상기 집계 결과를 기설정된 분류기준에 적용하여 4개 전략등급 중 하나로 자동 분류하는 단계;
를 포함하며,
상기 4개 전략등급은 핵심 강점, 성장 분야, 규모 우위, 육성 필요로 정의되는 것을 특징으로 하는 연구전략 도출 방법.

## 9. 요약서

### 【요약】

본 발명은 다차원 계량서지 지표 기반 연구자 종합평가 및 연구전략 도출 시스템에 관한 것이다.

본 발명에 따른 시스템은 FWCI, Top 10% 피인용, 상위저널 비율, 국제협력 FWCI 등 복수의 계량서지 지표를 핵심지표(80점)와 보조지표(10점)의 계층적 가중치 구조로 결합하여 연구자의 종합점수(90점 만점)를 산출한다.

또한 실제인용수에서 분야별 기대인용수를 감산한 인용갭(Citation Gap)을 산출하여, 상위저널 게재율이 높으나 인용이 부족한 연구자를 연구지원 우선대상으로 자동 식별한다.

학문분야별로는 품질(FWCI)과 규모(논문수)를 기준으로 핵심 강점, 성장 분야, 규모 우위, 육성 필요의 4분면 매트릭스에 자동 분류하여 전략적 의사결정을 지원한다.

본 발명은 기존 상용 시스템(SciVal, InCites 등)과 달리 단일 종합점수 제공, 인용갭 분석, 4분면 전략분류, 드릴다운 검증 기능을 통해 연구 평가의 객관성, 투명성, 활용성을 크게 향상시킨다.
