# 연구 전략 분석 공식 및 기준 설명서

## 공통 사항

- **데이터 범위**: Scopus 등재 논문만 대상 (KCI 전용 국내 등재지 제외)
- **분석 대상**: 전북대학교 소속 연구자만 (`primary_affiliation LIKE '%Jeonbuk%'`)
- **데이터 출처**: SciVal/Scopus에서 추출한 CSV 원시 데이터
- **FWCI**: Field-Weighted Citation Impact. Scopus가 산출하는 분야 보정 인용 영향력 지표. 1.0 = 세계 평균

## Tab 1: 연구 궤적 분석

### 1-1. 연속 성장 (growth_trajectory)

**목적**: 최근 3년간 매년 논문 수가 증가하고 있는 연구자를 식별

**선별 조건**:
- 최근 3개 연도(Y1, Y2, Y3)의 논문 수를 추적
- Y1 >= 1편 (최소 1편 이상)
- Y1 < Y2 < Y3 (매년 순차적으로 증가, 동일하면 제외)

**공식**:
```
성장률(%) = (Y3 - Y1) / Y1 × 100
```

**정렬 기준**: 성장률 내림차순

**사용 변수**:
| 변수 | 출처 | 설명 |
|---|---|---|
| Y1, Y2, Y3 | publication 테이블, year 컬럼 | 최근 3개 연도의 연구자별 논문 수 |

**연도 기준**:
- 기본: DB 내 최신 데이터 연도(max_data_year)를 기준으로 3년 역산
- 예: max_data_year=2025 → Y1=2023, Y2=2024, Y3=2025
- 분석기간 지정 시: min(지정 종료연도, max_data_year)를 기준으로 역산

**설계 근거**: 단순 논문수 비교. 자체 설계 공식 없이 팩트 데이터만 사용.

### 1-2. 감소 경보 (early_warning)

**목적**: 과거에 활발했으나 최근 연구 활동이 급감한 연구자를 조기 경보

**선별 조건**:
- 과거 3년 합계 >= 5편 (최소 활동량 보장)
- 최근 2년 연평균 < 과거 3년 연평균의 50%

**공식**:
```
과거 연평균 = (과거 3년 논문 합계) / 3
최근 연평균 = (최근 2년 논문 합계) / 2
감소율(%) = (1 - 최근 연평균 / 과거 연평균) × 100
```

**기간 구간** (max_data_year=2025 기준):
| 구간 | 연도 | 계산 |
|---|---|---|
| 과거 3년 | 2021, 2022, 2023 | check_end - 4 ~ check_end - 2 |
| 최근 2년 | 2024, 2025 | check_end - 1 ~ check_end |

**정렬 기준**: 감소율 내림차순

**임의 설정값**:
| 값 | 설정 | 근거 |
|---|---|---|
| 과거 최소 5편 | `past_count < 5` 필터 | 통계적으로 의미 있는 활동량을 판단하기 위한 최소 기준. 학술적 근거 없는 경험적 임계값 |
| 감소 임계 50% | `recent_avg < past_avg * 0.5` | 연평균이 절반 이하로 떨어진 경우를 "급감"으로 판단. 경험적 임계값 |
| 과거 3년 / 최근 2년 | 기간 분할 | 과거 추세를 판단하기에 3년이 적절하고, 최근 변화를 감지하기에 2년이 적절하다는 경험적 판단 |

**설계 근거**: 과거 대비 최근 활동량의 비율을 비교하는 단순 비율 계산. 50% 감소 임계값은 경험적으로 설정한 것이며, 학술적 표준은 아님.

### 1-3. 라이징 스타 (rising_star)

**목적**: 신진 연구자 중 이미 높은 연구 영향력을 보이는 유망 연구자를 식별

**선별 조건**:
- 최초 발표 연도 기준 경력 5년 이내 (`current_year - oldest_publication + 1 <= 5`)
- 최소 3편 이상 발표
- FWCI > 1.5 또는 h-index >= 5 (둘 중 하나 충족)

**공식**:
```
스타 점수 = FWCI × 40 + h-index × 3 + 논문수 × 2
```

**정렬 기준**: 스타 점수 내림차순

**가중치 설명**:
| 항목 | 가중치 | 이유 |
|---|---|---|
| FWCI × 40 | 최대 | 연구 품질(분야 보정 인용 영향력)이 가장 중요한 잠재력 지표. FWCI 값 자체가 소수(보통 0~5)이므로 높은 배수 필요 |
| h-index × 3 | 중간 | 지속적 연구 영향력 지표. 신진연구자는 h-index가 자연히 낮으므로 적당한 가중치 |
| 논문수 × 2 | 최소 | 생산성 지표. 양보다 질이 중요하므로 가장 낮은 가중치 |

**임의 설정값**:
| 값 | 설정 | 근거 |
|---|---|---|
| 경력 5년 | `career_years > 5` 필터 | "신진 연구자"의 범위를 5년으로 정의. 일반적으로 학술계에서 신진 연구자를 박사 후 5~7년 이내로 봄. 경험적 기준 |
| 최소 3편 | `total_pubs < 3` 필터 | 통계적 의미를 갖기 위한 최소 논문 수. 경험적 기준 |
| FWCI > 1.5 | 세계 평균(1.0)의 1.5배 이상. "우수"의 최소 기준으로 설정. 경험적 임계값 |
| h-index >= 5 | 5년 이내 경력에서 h-index 5는 매년 1편 이상의 인용 논문을 의미. 경험적 기준 |
| 가중치 40/3/2 | FWCI 중심 평가를 위한 경험적 비율. 학술적 근거 없음 |

**설계 근거**: 가중 합산 점수(weighted composite score). 가중치는 "적은 논문으로도 높은 영향력 = 높은 잠재력"이라는 가정에 기반한 경험적 설계. 학술 문헌에 기반한 공식이 아님.

## Tab 2: 사회적 영향력

### 2-1. 특허 인용 (patent_cited)

**목적**: 연구 성과가 특허에 인용된 연구자를 식별 (기술 이전/산업화 잠재력)

**선별 조건**:
- `is_patent_cited = 1`인 논문을 1편 이상 보유

**집계 방식**:
```
특허논문수 = 해당 연구자의 is_patent_cited=1 논문 수
특허수 = 해당 논문들의 main_patent_families 값 합계
```

**정렬 기준**: 특허수(total_patents) 내림차순

**사용 변수**:
| 변수 | 출처 | 설명 |
|---|---|---|
| is_patent_cited | SciVal 카테고리별 CSV | 특허에 인용된 논문 여부 (불리언) |
| main_patent_families | publication 테이블 | 해당 논문을 인용한 특허 패밀리 수 (Scopus 제공 원시 값) |

**설계 근거**: 자체 공식 없음. Scopus가 제공하는 특허 인용 데이터를 연구자 단위로 집계만 수행.

---

### 2-2. 정책 인용 (policy_cited)

**목적**: 연구 성과가 정책 문서에 인용된 연구자를 식별 (사회 정책 기여도)

**선별 조건**:
- `is_policy_cited = 1`인 논문을 1편 이상 보유

**집계 방식**:
```
정책논문수 = 해당 연구자의 is_policy_cited=1 논문 수
정책인용수 = 해당 논문들의 policy_citations 값 합계
```

**정렬 기준**: 정책인용수(total_policies) 내림차순

**사용 변수**:
| 변수 | 출처 | 설명 |
|---|---|---|
| is_policy_cited | SciVal 카테고리별 CSV | 정책 문서에 인용된 논문 여부 (불리언) |
| policy_citations | publication 테이블 | 해당 논문을 인용한 정책 문서 수 (Scopus 제공 원시 값) |

**설계 근거**: 자체 공식 없음. Scopus가 제공하는 정책 인용 데이터를 연구자 단위로 집계만 수행.

---

### 2-3. SDG 기여 (sdg_contribution)

**목적**: UN 지속가능발전목표(SDG)에 기여하는 연구를 수행하는 연구자를 식별

**선별 조건**:
- `is_SDG = 1`인 논문을 1편 이상 보유

**집계 방식**:
```
SDG논문수 = 해당 연구자의 is_SDG=1 논문 수
SDG분야수 = 해당 연구자 논문에서 추출된 고유 SDG 카테고리 수
SDG목표 = 기여한 SDG 목표명 목록 (최대 5개 표시)
```

**정렬 기준**: SDG논문수(sdg_pubs) 내림차순

**사용 변수**:
| 변수 | 출처 | 설명 |
|---|---|---|
| is_SDG | SciVal 카테고리별 CSV | SDG 관련 논문 여부 (불리언) |
| sustainable_development_goals_2025 | publication 테이블 | 해당 논문의 SDG 카테고리 (예: "SDG 7", "SDG 13") (Scopus 제공 원시 값) |

**설계 근거**: 자체 공식 없음. Scopus가 분류한 SDG 데이터를 연구자 단위로 집계만 수행.

## Tab 3: 전략 포트폴리오

### 3-1. 분야 전략 맵 (field_strategy_map)

**목적**: ASJC 분야별 논문수, 평균 FWCI, 국제협력 비율을 기반으로 분야 경쟁력을 매핑

**단위**: 연구자가 아닌 **분야(ASJC field)** 단위 분석

**선별 조건**:
- 해당 분야 논문 수 >= 10편 (통계적 유의성 확보)

**집계 방식**:
```
논문수 = 해당 분야에 속하는 전북대 논문 수
평균FWCI = 해당 분야 논문들의 FWCI 합계 / 논문수
국제비율(%) = (is_international=1 논문 수 / 논문수) × 100
Top피인용비율(%) = (is_top_cited=1 논문 수 / 논문수) × 100
Top저널비율(%) = (is_1=1 논문 수 / 논문수) × 100
총인용수 = 해당 분야 논문들의 citations 합계
```

**전략 등급 분류**:
```
if 평균FWCI >= 1.5 AND 국제비율 >= 40%:
    → "핵심 강점" (녹색)
elif 평균FWCI >= 1.0:
    → "성장 분야" (파랑)
elif 논문수 >= 50:
    → "규모 우위" (하늘색)
else:
    → "육성 필요" (노랑)
```

**정렬 기준**: 논문수 내림차순

**임의 설정값**:
| 값 | 설정 | 근거 |
|---|---|---|
| 최소 10편 | `count < 10` 필터 | 평균 FWCI 등 비율 지표의 통계적 의미를 위한 최소 표본. 경험적 기준 |
| FWCI >= 1.5 | "핵심 강점" 기준 | 세계 평균(1.0)의 1.5배. "우수"로 볼 수 있는 수준. 경험적 임계값 |
| 국제비율 >= 40% | "핵심 강점" 기준 | 국제 연구 협력의 활발함을 나타내는 기준. 경험적 임계값 |
| FWCI >= 1.0 | "성장 분야" 기준 | 세계 평균 이상이면 성장 가능성 있음. FWCI 정의에 기반 |
| 논문수 >= 50 | "규모 우위" 기준 | 연구 규모가 충분히 큰 분야. 경험적 기준 |

**설계 근거**: 4단계 전략 등급은 BCG 매트릭스 개념을 단순화하여 적용. FWCI(품질)와 국제비율(협력)의 조합으로 분야 경쟁력을 판단. 모든 임계값은 경험적 설정.

### 3-2. 협력 효과 (collab_effect)

**목적**: 연구자별 협력 유형(단독/기관내/국내/국제)에 따른 FWCI 차이를 분석

**선별 조건**:
- 총 논문수 >= 5편

**협력 유형 분류 우선순위** (논문별 1개만 배정):
```
1순위: is_international = 1 → "국제"
2순위: is_national_collab = 1 → "국내"
3순위: is_institutional_collab = 1 → "기관내"
4순위: is_single_author = 1 → "단독"
5순위: 해당 없음 → "기타"
```

**집계 방식**:
```
단독FWCI = 단독 논문들의 FWCI 평균
기관내FWCI = 기관내 협력 논문들의 FWCI 평균
국내FWCI = 국내 협력 논문들의 FWCI 평균
국제FWCI = 국제 협력 논문들의 FWCI 평균
```

**협력 부스트 공식**:
```
if 단독FWCI 존재 AND 단독FWCI > 0:
    협력부스트(%) = (국제FWCI - 단독FWCI) / 단독FWCI × 100
elif 국내FWCI 존재 AND 국내FWCI > 0:
    협력부스트(%) = (국제FWCI - 국내FWCI) / 국내FWCI × 100
else:
    협력부스트 = 0
```

**정렬 기준**: 협력부스트 내림차순

**임의 설정값**:
| 값 | 설정 | 근거 |
|---|---|---|
| 최소 5편 | `total_pubs < 5` 필터 | 유형별 FWCI 평균이 의미를 가지려면 최소한의 논문 수 필요. 경험적 기준 |

**설계 근거**: 협력 유형별 FWCI 평균을 비교하여 국제협력의 실질적 효과를 수치로 보여줌. 부스트 계산은 단독(또는 국내) 대비 국제협력 시 FWCI가 얼마나 높아지는지를 백분율로 표현. 자체 설계 공식.

---

### 3-3. 산학협력 (academic_corporate)

**목적**: 학술-기업 공동소속 저자가 포함된 논문을 보유한 연구자를 분석

**선별 조건**:
- `is_academic_corporate = 1`인 논문을 2편 이상 보유

**집계 방식**:
```
산학논문수 = 해당 연구자의 is_academic_corporate=1 논문 수
산학비율(%) = (산학논문수 / 해당 연구자의 전체 논문수) × 100
산학FWCI = 산학협력 논문들의 FWCI 평균
산학인용수 = 산학협력 논문들의 citations 합계
```

**정렬 기준**: 산학논문수(corp_pubs) 내림차순

**임의 설정값**:
| 값 | 설정 | 근거 |
|---|---|---|
| 최소 2편 | `corp_pubs < 2` 필터 | 1회성이 아닌 지속적 산학협력을 판단하기 위한 최소 기준. 경험적 기준 |

**사용 변수**:
| 변수 | 출처 | 설명 |
|---|---|---|
| is_academic_corporate | SciVal 카테고리별 CSV | 학술+기업 공동소속 저자 포함 논문 여부 (불리언, Scopus 분류) |

**설계 근거**: 자체 공식 없음 (비율, 평균만 사용). Scopus가 분류한 산학협력 데이터를 연구자 단위로 집계.

## 요약: 자체 설계 공식 vs Scopus 원시 데이터

| 분석 | 유형 | 설명 |
|---|---|---|
