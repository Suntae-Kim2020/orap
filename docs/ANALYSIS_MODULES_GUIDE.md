# JBNU ORAP 연구자 분석 시스템 가이드

전북대학교 연구진흥을 위한 연구자 분석 시스템의 각 기능별 산출방식, 특징, 활용방안을 설명합니다.

---

## 1. 우수연구자 랭킹

### 1.1 산출방식

우수연구자 점수는 **핵심지표(80점 만점)**와 **보조지표(10점 만점)**로 구성되며, 각 지표는 **개별 논문별로 점수를 산출한 후 평균**을 계산합니다.

#### 핵심지표 (80점 만점)

| 지표 | 배점 | 산출방식 |
|------|------|----------|
| FWCI (분야가중인용영향력) | 35점 | 논문별 FWCI 값을 점수로 변환 후 중위값 사용. FWCI 10+ → 35점, 8+ → 30점, 6+ → 25점, 4+ → 20점, 2+ → 15점, 그 외 → 10점 |
| Top 10% 피인용 | 20점 | 각 논문이 해당 분야 상위 10% 피인용에 해당하면 20점, 아니면 10점. 전체 논문의 평균 계산 |
| 상위 저널 게재 | 15점 | 각 논문이 SNIP/CiteScore/SJR 백분위 상위 10% 저널이면 15점, 아니면 5점. 전체 논문의 평균 계산 |
| 국제협력 FWCI | 10점 | 국제공저 논문의 FWCI가 2.0+ → 10점, 1.5+ → 7점, 1.0+ → 4점, 그 외 → 1점. 국제공저 논문만의 평균 계산 |

#### 보조지표 (10점 만점)

| 지표 | 배점 | 산출방식 |
|------|------|----------|
| SDG 관련 연구 | 3점 | SDG(지속가능발전목표) 관련 논문이 1편 이상이면 3점 |
| Open Access | 2점 | OA 논문이 1편 이상이면 2점 |
| Topic Prominence | 5점 | Prominence Percentile 90% 이상 토픽 논문이 1편 이상이면 5점 |

#### FWCI 계산 방식 선택

- **중위값 (기본값, 권장)**: 이상치의 영향을 받지 않아 안정적인 평가 가능
- **산술평균**: 극단적으로 높은 FWCI 논문에 영향을 받아 값이 왜곡될 수 있음

### 1.2 서비스 특징

- **사전 계산 기반 고속 조회**: researcher_score 테이블에 점수를 미리 계산하여 저장, 0.03초 내 결과 반환
- **개별 논문 기반 공정한 평가**: 단순 집계가 아닌 논문별 점수의 평균으로 계산하여 논문 수에 따른 왜곡 방지
- **전북대 소속 연구자 한정**: primary_affiliation이 'Jeonbuk National University'인 연구자만 대상
- **최소 논문 수 필터**: 기본 10편 이상 논문을 보유한 연구자만 표시 (조정 가능)

### 1.3 활용방안

- **우수연구자 포상 대상 선정**: 총점 상위 연구자를 연구 업적 우수자로 선정
- **연구비 지원 우선순위 결정**: 핵심지표 점수가 높은 연구자에게 연구비 우선 배분
- **THE/QS 평가 대응**: 국제협력, 상위저널 게재, 피인용도 등 세계대학평가 지표와 연계된 점수 체계
- **부문별 강점 분석**: 개별 지표 점수를 통해 연구자의 강점/약점 파악 및 맞춤형 지원

## 2. 잠재 연구자 발굴 모듈

### 2.1 최근 3년 성장률 높은 연구자

#### 산출방식

```
성장률 = ((최근3년 논문비율 / 기대 논문비율) - 1) × 100

- 최근3년 논문비율 = 2022년 이후 논문 수 / 전체 논문 수
- 기대 논문비율 = 3 / 연구경력(년)
- 연구경력 = 최근 논문 연도 - 최초 논문 연도 + 1
```

예시: 경력 15년 연구자가 총 30편 중 최근 3년에 15편을 발표한 경우
- 기대 비율: 3/15 = 20%
- 실제 비율: 15/30 = 50%
- 성장률: (50%/20% - 1) × 100 = **+150%**

#### 서비스 특징

- 최근 3년 논문이 3편 이상인 연구자만 대상
- 경력 3년 이하 신진연구자는 제외 (성장률 산출 불가)
- 모든 논문 데이터를 1회 쿼리로 가져와 메모리에서 계산 (고속 처리)

#### 활용방안

- **신진연구자 지원 대상 발굴**: 최근 연구 활동이 활발한 연구자 식별
- **연구역량 강화 프로그램 대상자 선정**: 성장세가 뚜렷한 연구자에게 추가 지원
- **연구 트렌드 파악**: 어떤 분야에서 연구 활동이 활발해지고 있는지 분석

---

### 2.2 FWCI 높지만 논문 수 적은 연구자

#### 산출방식

```
효율성 점수 = FWCI / log(논문 수 + 1)
```

- 대상: 논문 수 5~30편, FWCI 1.5 이상인 연구자
- 효율성 점수가 높을수록 적은 논문으로 높은 영향력을 보유

예시: FWCI 3.0, 논문 10편인 연구자
- 효율성 = 3.0 / log(11) ≈ 3.0 / 2.4 = **1.25**

#### 서비스 특징

- 양적 성과보다 질적 성과에 초점
- 논문 수가 적어 기존 평가에서 간과될 수 있는 연구자 발굴
- FWCI 1.5 이상은 세계 평균의 1.5배 수준으로 우수한 영향력

#### 활용방안

- **연구 지원 효율성 극대화**: 적은 투자로 높은 성과를 낼 가능성이 높은 연구자 지원
- **잠재적 스타 연구자 발굴**: 현재 논문 수는 적지만 질적 성과가 우수한 연구자 조기 발굴
- **연구 환경 개선 대상자 선정**: 연구 시간/자원 확보 시 큰 성장이 기대되는 연구자

---

### 2.3 Topic Prominence 90+ 분야 연구자

#### 산출방식

- Scopus의 Topic Prominence Percentile이 90% 이상인 논문을 보유한 연구자 추출
- 고Prominence 논문 수와 최대 Prominence 값으로 정렬
- 최소 2편 이상의 고Prominence 논문 보유자만 대상

Topic Prominence Percentile이란:
- Scopus가 정의한 96,000개 연구 토픽의 성장세를 측정
- 최근 인용 모멘텀, 최근 조회수, CiteScore 등을 기반으로 계산
- 90% 이상은 가장 빠르게 성장하는 상위 10% 연구 분야

#### 서비스 특징

- 떠오르는 연구 분야를 선점한 연구자 식별
- 단순 인용 수가 아닌 연구 분야의 미래 성장 가능성에 초점
- 주요 연구 토픽명 함께 제공

#### 활용방안

- **미래 유망 분야 투자**: 성장하는 연구 분야에 선제적 투자
- **신규 연구센터 설립 검토**: 고Prominence 분야 연구자 그룹을 중심으로 연구센터 구성
- **산학협력 연계**: 떠오르는 기술 분야 연구자와 기업 매칭

## 3. 고인용 논문 유도 대상 모듈

### 3.1 상위 저널 게재율 높지만 인용수 낮은 연구자

#### 산출방식

```
인용 갭 = 기대 인용수 - 실제 인용수
기대 인용수 = 논문 수 × 15 (상위 저널 평균 기대치)
```

- 대상: 상위 저널 게재율 30% 이상, 논문 수 10편 이상
- 인용 갭이 클수록 기대 대비 인용이 부족

예시: 논문 50편, 실제 인용 500회인 연구자
- 기대 인용: 50 × 15 = 750회
- 인용 갭: 750 - 500 = **250회 부족**

#### 서비스 특징

- 저널 품질은 우수하나 인용 성과가 미흡한 연구자 식별
- 연구의 질은 검증되었으나 가시성/홍보가 부족한 경우 해당
- 인용 갭이 양수인 경우만 표시 (기대보다 인용이 낮은 경우)

#### 활용방안

- **연구 홍보 지원**: 논문 홍보, 언론 보도, SNS 마케팅 등 가시성 향상 지원
- **학술 네트워킹 지원**: 국제학회 참가, 초청강연 등 네트워킹 기회 제공
- **후속 연구 지원**: 고인용 논문으로 발전할 수 있는 후속 연구 지원

---

### 3.2 국제협력 확대 시 인용 향상 가능한 연구자

#### 산출방식

```
대상 조건:
- 논문 수 10편 이상
- FWCI 중위값 1.0 이상 (세계 평균 이상의 영향력)
- 국제협력 비율 30% 미만
```

국제협력 비율 = 국제공저 논문 수 / 전체 논문 수 × 100

#### 서비스 특징

- 연구 역량은 우수하나 국제협력이 부족한 연구자 식별
- 국제공저 논문은 일반적으로 단독/국내 공저보다 인용이 높음
- 국제협력 FWCI도 함께 표시하여 현재 국제협력의 질적 수준 파악 가능

#### 활용방안

- **국제공동연구 매칭**: 해외 연구자/기관과의 공동연구 기회 제공
- **해외 연수 지원**: 해외 유수 연구기관 방문연구 지원
- **국제학회 참가 지원**: 국제 네트워크 구축을 위한 학회 참가비 지원

---

### 3.3 Top 10% 저널 게재 경험 있지만 Top 10% 피인용 없는 연구자

#### 산출방식

```
대상 조건:
- 상위 10% 저널 게재율 > 0% (게재 경험 있음)
- 논문 수 10편 이상
- 상위 10% 피인용 논문 수 = 0 (아직 없음)
```

#### 서비스 특징

- 저널 선택 능력은 검증되었으나 인용 극대화 전략이 부족한 연구자
- 상위 저널에 게재할 수 있는 연구 수준을 보유
- 인용 전략 개선 시 Top 10% 피인용 달성 가능성 높음

#### 활용방안

- **인용 극대화 전략 교육**: 논문 작성법, 키워드 최적화, 초록 작성법 등 교육
- **연구 영향력 컨설팅**: 전문가를 통한 연구 홍보 전략 수립 지원
- **후속 연구 방향 제안**: 인용 가능성 높은 연구 주제 발굴 지원

## 4. 공동연구 분석 모듈

### 4.1 국제협력 없는 고성과 연구자 (지원 대상)

#### 산출방식

```
대상 조건:
- 논문 수 15편 이상
- FWCI 중위값 1.0 이상
- 국제협력 논문 수 2편 이하
```

#### 서비스 특징

- 높은 연구 성과를 보이지만 국제협력이 거의 없는 연구자
- 국제협력 지원 시 가장 큰 성장 잠재력을 보유
- FWCI 내림차순 정렬로 가장 우수한 연구자부터 표시

#### 활용방안

- **국제협력 우선 지원 대상**: 국제공동연구 프로그램 우선 참여 기회 제공
- **해외 연구기관 MOU 활용**: 기존 MOU 체결 기관과의 교류 연구자로 추천
- **글로벌 연구 네트워크 구축**: 해당 연구자 중심의 국제 연구팀 구성 지원

---

### 4.2 공동연구 활발 + 고인용 연구자 (롤모델/멘토)

#### 산출방식

```
대상 조건:
- 논문 수 20편 이상
- 국제협력 논문 5편 이상
- FWCI 중위값 1.5 이상
```

정렬 기준: 국제협력 FWCI × 국제협력 논문 수 (내림차순)

#### 서비스 특징

- 국제협력과 인용 성과 모두 우수한 검증된 연구자
- 국제협력 성공 노하우를 보유한 롤모델
- 국제협력 비율과 국제협력 FWCI를 함께 제공

#### 활용방안

- **멘토링 프로그램 운영**: 신진연구자 대상 국제협력 멘토로 활용
- **베스트 프랙티스 공유**: 성공적인 국제협력 사례 발표 및 공유
- **연구팀 리더 역할**: 대형 국제공동연구 프로젝트의 PI로 추천
- **신진연구자 공동연구 매칭**: 국제협력 지원 대상자와 멘토 매칭

---

### 4.3 분야별 협력 허브 연구자

#### 산출방식

```
허브 점수 = 분야 내 논문 수 × 고유 공저자 수
```

- 분야: ASJC (All Science Journal Classification) 분류 기준
- 분야 내 논문 5편 이상인 연구자만 대상
- 각 분야별 상위 3명의 허브 연구자 추출

예시: 의학 분야에서 50편 발표, 200명의 고유 공저자와 협력
- 허브 점수: 50 × 200 = **10,000**

#### 서비스 특징

- 특정 연구 분야에서 가장 넓은 협력 네트워크를 보유한 연구자
- 분야별로 구분하여 각 분야의 핵심 연결자 식별
- 고유 공저자 수를 통해 네트워크의 다양성 측정

#### 활용방안

- **분야별 연구 허브 구축**: 해당 연구자를 중심으로 분야별 연구클러스터 형성
- **학제간 연구 촉진**: 서로 다른 분야의 허브 연구자 연결로 융합연구 유도
- **신진연구자 네트워킹**: 분야 진입을 원하는 신진연구자에게 허브 연구자 소개
- **외부 협력 창구**: 해당 분야 외부 협력 요청 시 허브 연구자를 창구로 활용

|----------|---------------|----------|
| 연구 영향력 (Citations) | 고인용 유도 대상 모듈 | 인용 갭이 큰 연구자 집중 지원 |
| 국제 연구 네트워크 | 공동연구 분석 모듈 | 국제협력 없는 고성과자에게 해외 협력 기회 제공 |
| 연구 생산성 | 잠재 연구자 발굴 모듈 | 성장률 높은 연구자 지원으로 논문 수 증가 |
| 연구 품질 | 우수연구자 랭킹 | 상위저널/FWCI 점수 높은 연구자 집중 육성 |

### 5.2 연구자 생애주기별 지원

| 단계 | 추천 분석 기능 | 지원 방향 |
|------|---------------|----------|
| 신진연구자 | 최근 3년 성장률, 고FWCI 저논문 | 연구 기반 구축, 초기 성과 창출 지원 |
| 중견연구자 | 국제협력 확대 대상, Top저널-Top피인용 無 | 국제화, 인용 극대화 전략 |
| 원로연구자 | 롤모델/멘토, 분야별 허브 | 멘토링, 네트워크 리더 역할 |

### 5.3 데이터 기반 의사결정

- **정기 모니터링**: 월/분기별로 각 모듈 결과를 모니터링하여 변화 추이 파악
- **지원 성과 측정**: 지원 전후 해당 연구자의 점수 변화를 통해 지원 효과 측정
- **정책 수립 근거**: 객관적 데이터를 기반으로 연구 지원 정책 수립

## 6. 기술 사양

### 6.1 데이터 소스

- **Scopus/SciVal**: 논문, 인용, FWCI, Topic Prominence 등 서지 데이터
- **저자 정보**: Scopus Author ID 기반 연구자 식별
- **저널 지표**: SNIP, CiteScore, SJR 백분위

### 6.2 성능 최적화

- 사전 계산된 researcher_score 테이블 활용 (우수연구자 랭킹)
- 메모리 캐싱 기반 집계 (잠재연구자, 허브연구자 등)
- 평균 응답 시간: 0.2~0.3초

### 6.3 갱신 주기

- Scopus 데이터 업데이트 시 점수 재계산 필요
- `/api/recalculate_scores` API를 통해 수동 재계산 가능
