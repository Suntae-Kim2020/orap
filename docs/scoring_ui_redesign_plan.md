# 점수 설정 UI 재설계 계획

## 기본 원칙
- **총점 고정**: 핵심지표 80점 + 보조지표 10점 = **90점 만점**
- **조정 가능한 것**: 각 카테고리 내 지표별 **비율(%)** 만 조정
- **UI 단순화**: 중복 컨트롤 제거, 직관적 인터페이스

---

## 변경 전 (현재 문제점)

```
프리셋 선택 드롭다운
  ↓
총점 배분 (핵심 +/- / 보조 +/-)  ← 제거 대상
  ↓
빠른 프리셋 버튼 5개             ← 제거 대상 (드롭다운과 중복)
  ↓
핵심지표 세부 배분 + 빠른버튼 3개 ← 빠른버튼 제거
  ↓
보조지표 세부 배분 + 빠른버튼 3개 ← 빠른버튼 제거
```

**문제:**
1. 총점 배분 vs 프리셋 충돌
2. 빠른 프리셋 버튼이 드롭다운과 중복
3. 개별 빠른버튼이 프리셋과 충돌
4. 점수 계산 오류 (총점 변경 시 반영 안됨)

## 수정 내용

### 1. 제거할 요소
- [ ] "총점 배분" 섹션 전체 (핵심/보조 총점 +/- 버튼)
- [ ] "빠른 프리셋 적용" 버튼 5개 (기본, 인용중심, 국제협력, 품질중심, SDG중심)
- [ ] 핵심지표 하단 빠른버튼 3개 (균등25%, 인용중심, 국제협력)
- [ ] 보조지표 하단 빠른버튼 3개 (균등33%, SDG중심, 기본)
- [ ] 자동조정 버튼 (비율 합이 항상 100%가 되도록 프리셋에서 관리)

### 2. 유지/수정할 요소
- [x] 프리셋 선택 드롭다운 (유지)
- [x] 핵심지표 세부 배분 테이블 (읽기 전용으로 변경)
- [x] 보조지표 세부 배분 테이블 (읽기 전용으로 변경)
- [x] "이 설정으로 랭킹 조회" 버튼 (유지)
- [x] "현재 설정 저장" 버튼 (유지 - 사용자 정의 프리셋 생성용)

### 3. 백엔드 수정
- [ ] 프리셋 테이블에서 total_core, total_supplementary 컬럼 값 모두 80, 10으로 고정
- [ ] API 응답에서 총점 정보 제거 또는 고정값 반환

### 4. JavaScript 수정
- [ ] `scoringSettings.totalCore = 80` 고정
- [ ] `scoringSettings.totalSupp = 10` 고정
- [ ] `applyFullPreset()` 함수 제거
- [ ] `adjustTotal()` 함수 제거
- [ ] `onTotalChange()` 함수 제거
- [ ] 비율 입력을 읽기 전용으로 변경 (프리셋으로만 조정)

## 프리셋 정의 (비율만, 총점 고정)

| 프리셋 | FWCI | Top10 | 상위저널 | 국제협력 | SDG | OA | Topic |
|--------|------|-------|----------|----------|-----|-----|-------|
| 기본 설정 | 25% | 25% | 25% | 25% | 30% | 30% | 40% |
| 인용 중심 | 35% | 35% | 15% | 15% | 30% | 30% | 40% |
| 국제협력 중심 | 20% | 20% | 20% | 40% | 30% | 30% | 40% |
| 품질 중심 | 30% | 20% | 35% | 15% | 30% | 30% | 40% |
| SDG 중심 | 25% | 25% | 25% | 25% | 50% | 25% | 25% |

**점수 계산:**
- 핵심지표 점수 = 80 × (해당 비율 / 100)
- 보조지표 점수 = 10 × (해당 비율 / 100)

## 예상 결과

1. **사용자 경험 개선**: 프리셋 선택만으로 간단히 설정 완료
2. **혼란 제거**: 중복 컨트롤 없음, 총점 변경 불가
3. **일관성**: 모든 랭킹이 90점 만점 기준으로 비교 가능
4. **유지보수 용이**: 코드 단순화
