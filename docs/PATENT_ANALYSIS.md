# ORAP 시스템 특허 분석서

## 개요

- **발명의 명칭(안)**: 다차원 계량서지 지표 기반 연구자 종합평가 및 연구전략 도출 시스템
- **출원인**: 전북대학교 산학협력단 / 김선태
- **발명자**: 김선태
- **기술분야**: 연구성과 분석 시스템, 계량서지학(Bibliometrics), 연구정보 시스템

---

## 1. 특허 출원 가능 발명 (3건)

### 발명 1: 다차원 복합지표 기반 연구자 종합점수 산정 방법

#### 1.1 발명의 요약
복수의 계량서지 지표(FWCI, Topic Prominence, 인용갭, 상위저널 비율, 국제협력)를 **계층적 가중치 구조**로 결합하여 연구자의 종합 연구력을 정량화하는 방법

#### 1.2 청구항(안)

**[독립항 1]**
연구자의 연구성과를 평가하는 컴퓨터 구현 방법에 있어서,
(a) 연구자의 논문 데이터로부터 필드가중인용지수(FWCI)를 추출하는 단계;
(b) 상기 FWCI를 기설정된 구간별 점수표에 매핑하여 FWCI 점수(최대 35점)를 산출하는 단계;
(c) 상기 연구자의 Top 10% 피인용 논문 수를 기준으로 피인용 점수(최대 20점)를 산출하는 단계;
(d) 상기 연구자의 논문 중 상위저널(SNIP/CiteScore/SJR 상위 10%) 게재 비율을 산출하여 저널품질 점수(최대 15점)를 산출하는 단계;
(e) 상기 연구자의 국제협력 논문의 평균 FWCI를 산출하여 국제협력 점수(최대 10점)를 산출하는 단계;
(f) 상기 (b)~(e) 단계의 점수를 합산하여 핵심지표 점수를 산출하는 단계;
(g) SDG 관련 연구, 오픈액세스, Topic Prominence를 포함하는 보조지표 점수(최대 10점)를 산출하는 단계;
(h) 상기 핵심지표 점수와 보조지표 점수를 합산하여 연구자 종합점수를 산출하는 단계;
를 포함하는 것을 특징으로 하는 연구자 종합평가 방법.

**[종속항 2]**
제1항에 있어서, 상기 FWCI는 개별 논문 FWCI의 **중앙값(median)** 또는 **평균값(mean)** 중 사용자 선택에 따라 적용되는 것을 특징으로 하는 방법.

**[종속항 3]**
제1항에 있어서, 상기 방법은 각 점수 항목별로 기여한 개별 논문 목록을 **드릴다운(drilldown) 방식**으로 제공하여 점수 산정의 근거를 투명하게 검증할 수 있도록 하는 단계를 더 포함하는 것을 특징으로 하는 방법.

#### 1.3 점수 산정 상세 로직

| 지표 | 배점 | 산정 기준 |
|------|------|----------|
| FWCI | 35점 | ≥10: 35점, ≥8: 30점, ≥6: 25점, ≥4: 20점, ≥2: 15점, <2: 10점 |
| Top 10% 피인용 | 20점 | ≥3편: 20점, ≥1편: 15점, 0편: 10점 |
| 상위저널 비율 | 15점 | ≥10%: 15점, <10%: 5점 |
| 국제협력 FWCI | 10점 | ≥2.0: 10점, ≥1.5: 7점, ≥1.0: 4점, <1.0: 1점 |
| SDG 관련 | 3점 | SDG 논문 有: 3점, 無: 0점 |
| Open Access | 2점 | OA 논문 有: 2점, 無: 0점 |
| Topic Prominence | 5점 | 평균 ≥90%: 5점, <90%: 0점 |

### 발명 2: 인용갭(Citation Gap) 기반 연구지원 대상자 식별 방법

#### 2.1 발명의 요약
연구자의 **기대인용수**와 **실제인용수** 간의 차이(인용갭)를 산출하여, 상위저널 게재 실적 대비 인용이 저조한 연구자를 식별하고 맞춤형 연구지원 전략을 제안하는 방법

#### 2.2 청구항(안)

**[독립항 1]**
연구지원 대상자를 식별하는 컴퓨터 구현 방법에 있어서,
(a) 연구자의 각 논문에 대해 해당 분야의 평균 인용수(Field Citation Average)를 조회하는 단계;
(b) 상기 분야별 평균 인용수의 합계를 산출하여 **기대인용수(Expected Citations)**를 산정하는 단계;
(c) 상기 연구자의 논문들이 실제로 받은 인용수 합계를 산출하여 **실제인용수(Actual Citations)**를 산정하는 단계;
(d) 상기 실제인용수에서 상기 기대인용수를 감산하여 **인용갭(Citation Gap)**을 산출하는 단계;
(e) 상기 인용갭이 음수(-)인 연구자 중 상위저널 게재비율이 기설정된 임계값(30%) 이상인 연구자를 **연구지원 우선대상**으로 분류하는 단계;
(f) 상기 분류된 연구자에 대해 "홍보/네트워킹 지원 필요" 등의 맞춤형 지원전략을 제안하는 단계;
를 포함하는 것을 특징으로 하는 연구지원 대상자 식별 방법.

**[종속항 2]**
제1항에 있어서, 상기 방법은 인용갭을 기준으로 연구자를 오름차순 정렬하여 지원 우선순위를 제공하는 단계를 더 포함하는 것을 특징으로 하는 방법.

#### 2.3 인용갭 산출 공식

```
인용갭(Citation Gap) = 실제인용수(Σ citations) - 기대인용수(Σ field_citation_average)

- 인용갭 < 0: 분야 평균 대비 인용 부족 → 지원 필요
- 인용갭 ≥ 0: 분야 평균 이상 → 정상
```

#### 2.4 지원대상 선별 조건

| 조건 | 임계값 | 의미 |
|------|--------|------|
| 상위저널 게재비율 | ≥ 30% | 연구 품질은 우수 |
| 논문 수 | ≥ 10편 | 충분한 연구 활동 |
| 인용갭 | < 0 | 기대 대비 인용 부족 |

### 발명 3: 학문분야별 연구전략 자동분류 시스템

#### 3.1 발명의 요약
학문분야(ASJC)별로 **논문규모**와 **연구품질(FWCI)** 두 축을 기준으로 4사분면 매트릭스에 배치하여 자동으로 전략등급을 부여하는 시스템

#### 3.2 청구항(안)

**[독립항 1]**
기관의 학문분야별 연구전략을 도출하는 컴퓨터 구현 방법에 있어서,
(a) 논문 데이터베이스로부터 ASJC(All Science Journal Classification) 분야 코드를 추출하는 단계;
(b) 각 분야별로 논문 수, 평균 FWCI, 국제협력 비율을 집계하는 단계;
(c) 상기 집계 결과를 기설정된 분류기준에 적용하여 4개 전략등급 중 하나로 자동 분류하는 단계;
(d) 상기 분류 결과를 2×2 매트릭스 형태로 시각화하여 제공하는 단계;
를 포함하며,
상기 4개 전략등급은:
- **핵심 강점**: FWCI ≥ 1.5 AND 국제협력비율 ≥ 40%
- **성장 분야**: FWCI ≥ 1.0
- **규모 우위**: 논문 수 ≥ 50편
- **육성 필요**: 상기 조건에 해당하지 않는 분야
로 정의되는 것을 특징으로 하는 연구전략 도출 방법.

**[종속항 2]**
제1항에 있어서, 상기 방법은 복수의 학문분야를 동시에 선택하여 비교 분석하는 단계를 더 포함하는 것을 특징으로 하는 방법.

**[종속항 3]**
제1항에 있어서, 상기 각 분야에 대해 Top 저널 게재비율, Top 10% 피인용 비율, SDG 관련 비율, 산학협력 비율, 특허인용 비율을 추가 지표로 산출하는 단계를 더 포함하는 것을 특징으로 하는 방법.

#### 3.3 전략등급 분류 매트릭스

```
                    품질(FWCI)
                 낮음         높음
           ┌──────────┬──────────┐
     높음  │ 규모 우위 │ 핵심 강점 │
 규모      │  (info)  │ (success)│
(논문수)   ├──────────┼──────────┤
     낮음  │ 육성 필요 │ 성장 분야 │
           │ (warning)│ (primary)│
           └──────────┴──────────┘
```

## 2. 선행기술 대비 차별점

### 2.1 주요 선행기술

| 선행기술 | 개발사 | 특징 |
|----------|--------|------|
| **SciVal** | Elsevier | Scopus 기반 연구성과 분석, FWCI 제공 |
| **InCites** | Clarivate | Web of Science 기반, JIF/CNCI 제공 |
| **Dimensions** | Digital Science | Altmetric 포함 종합 분석 |
| **Pure** | Elsevier | 연구정보관리시스템(CRIS) |

### 2.2 본 발명의 차별점

| 구분 | SciVal/InCites | 본 발명(ORAP) |
|------|----------------|---------------|
| **점수 통합** | 개별 지표 나열식 제공 | 계층적 가중치 기반 **단일 종합점수** 산출 |
| **인용갭 분석** | 미지원 | **기대인용-실제인용** 갭 분석으로 지원대상 식별 |
| **전략분류** | 수동 해석 필요 | **4분면 자동분류** + 전략등급 자동 부여 |
| **점수 검증** | 블랙박스 | **논문별 드릴다운**으로 투명한 근거 제시 |
| **FWCI 처리** | 평균만 제공 | **평균/중앙값 선택** 가능 (이상치 대응) |
| **비용** | 고가 라이선스 | 기관 자체 구축 가능 |

### 2.3 기술적 차별점 상세

#### (1) 계층적 복합점수 산정 (발명 1)

**선행기술의 한계:**
- SciVal: FWCI, h-index, 논문수 등을 개별적으로 표시
- 사용자가 지표들을 종합하여 연구자를 평가해야 함
- 지표 간 가중치나 통합 방법론 부재

**본 발명의 해결:**
```
종합점수 = 핵심지표(80점) + 보조지표(10점)

핵심지표 = FWCI(35) + Top피인용(20) + 상위저널(15) + 국제협력(10)
보조지표 = SDG(3) + OA(2) + TopicProm(5)
```
- 각 지표의 배점과 구간 기준을 명확히 정의
- 단일 수치로 연구자 간 비교 가능
- 드릴다운을 통해 점수 산정 근거 투명하게 공개

#### (2) 인용갭 기반 지원대상 식별 (발명 2)

**선행기술의 한계:**
- 인용수 절대값 또는 FWCI만 제공
- "좋은 저널에 게재했으나 인용이 적은" 연구자 식별 불가
- 연구지원 우선순위 결정 기준 부재

**본 발명의 해결:**
```
인용갭 = Σ(실제인용) - Σ(분야평균인용)

식별조건: 인용갭 < 0 AND 상위저널비율 ≥ 30% AND 논문수 ≥ 10
```
- 분야별 기대인용수를 기준으로 상대평가
- 연구 품질은 우수하나 인용이 부족한 연구자 자동 식별
- 맞춤형 지원전략(홍보, 네트워킹) 자동 제안

#### (3) 4분면 전략분류 자동화 (발명 3)

**선행기술의 한계:**
- 분야별 데이터는 제공하나 전략적 해석은 사용자 몫
- 분야 간 비교를 위한 표준화된 분류체계 부재
- 의사결정 지원 기능 미약

**본 발명의 해결:**
```
IF FWCI ≥ 1.5 AND 국제비율 ≥ 40% → "핵심 강점"
ELSE IF FWCI ≥ 1.0 → "성장 분야"
ELSE IF 논문수 ≥ 50 → "규모 우위"
ELSE → "육성 필요"
```
- 명확한 임계값 기반 자동 분류
- 2×2 매트릭스 시각화로 직관적 이해
- 분야별 투자/육성 전략 수립 지원

## 5. 결론

본 ORAP 시스템은 기존 상용 연구분석 도구(SciVal, InCites)와 비교하여 다음의 **기술적 차별점**을 보유하고 있어 특허 등록 가능성이 있음:

1. **계층적 가중치 기반 종합점수 산정 알고리즘**
2. **인용갭 분석을 통한 연구지원 대상자 자동 식별 방법**
3. **4분면 매트릭스 기반 학문분야 전략 자동분류 시스템**

특히 **발명 2(인용갭 분석)**는 선행기술에서 찾기 어려운 새로운 개념으로, 특허 등록 가능성이 가장 높음.
